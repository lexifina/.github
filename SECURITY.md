# Security

Please report security problems privately to [hello@lexifina.com](mailto:hello@lexifina.com) with “Security” in the subject, rather than in a public issue. Include what you found, how to reproduce it and what it affects. We will acknowledge your report and keep you updated while we fix it.

How Lexifina protects customer data is described at [lexifina.com/security](https://lexifina.com/security).
